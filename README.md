# Big Cheese Eventing — published site

This repository hosts the public website for **Big Cheese Eventing**, live at
**https://bigcheeseeventing.com**.

## How it works

- The site is a **static build, published automatically by CI** to the `gh-pages`
  branch, which GitHub Pages serves at the custom domain above.
- **Do not edit `gh-pages` by hand** — it is replaced in full (a single fresh
  commit) on every deploy, so manual changes are lost.
- This `main` branch is an intentional placeholder. The application source is
  maintained separately, in a private repository.
